拾音 · 滚动歌词 MV 生成器

这是适用于 Windows 10（2004 或以上）/ Windows 11 的 64 位应用程序。

安装目录可以在下一步自行修改。安装包仅包含应用程序及轻量引导组件，大小不超过 50 MB。

如果缺少 .NET 桌面运行环境或 WebView2，安装程序会联网准备这些组件。因此，完整安装及后续视频渲染所占磁盘空间会大于安装包体积。

首次启动后会检测 FFmpeg 与 Python。缺失时，只有点击“确定，下载并安装”才会下载。FFmpeg 和 Python 保存在当前用户的数据目录，不会修改系统 PATH。

支持导入 MP3、FLAC、WAV、M4A、AAC、OGG、Opus、WMA、AIFF 等音乐，以及 MP4、MKV、MOV、AVI、WebM、WMV、FLV、TS 等背景视频。程序会读取歌曲标签、封面和同名 LRC，再尝试搜索公开歌词库。公开库未必收录每首歌，可以自行导入 LRC 时间轴歌词。

部分格式首次打开时会准备兼容预览，可以取消；实际导出继续读取原始素材。

左侧“批量导出”支持多首音乐、视频库和风格随机分配。可以统一或分组设置命名、画质、帧率与编码，输出 MP4、MKV、MOV 或 WebM。停止批量任务会保留已完成的视频。

音乐和视频只在本机处理。在线歌词查询仅发送歌曲标签及搜索关键词。
