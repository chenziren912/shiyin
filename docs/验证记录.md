## 0.4.0 扩展导出编码

- 原界面限制了可选编码器，并非 FFmpeg 仅支持原来的编码。弹窗现分为文件与视频编码、画质与码率、速度与视频细节、音频编码四组。单首和批量均支持 MP4 / MKV / MOV / WebM，视频提供 H.264、H.265、AV1、VP9、VP8、ProRes、FFV1；音频提供 AAC、Opus、MP3、FLAC、ALAC、PCM 16 / 24 位与 Vorbis。
