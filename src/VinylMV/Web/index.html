使用说明

  1. 导入音乐文件

    优先读取同名 LRC、内嵌歌词和封面，随后根据歌名、歌手、专辑和时长匹配公开歌词库。

  2. 选择背景视频

    短视频自动循环至歌曲结束。也可保留纯色背景，或手动更换唱片封面。

  3. 调整并生成

    设置音量、背景亮度、字幕大小和保存位置。预览确认后生成视频，右侧歌词随时间滚动。

在线歌词库无法覆盖每首歌。找不到匹配版本时可导入本地 LRC；仅有纯文本的歌词无法提供准确时间轴。软件只向歌词服务发送歌曲标签，音视频由本机处理。

设备优化与并发导出

默认最多 3 个任务。先使用测速更快的编码器，再根据 CPU 与 GPU 占用逐步增加任务，优先分配给占用较低的一侧；合成画面仍需要 CPU。无法读取占用时保守运行，设为 1 可逐首导出。未同意设备检测时使用手动编码。

同意检测后，首次使用某种格式、码率、分辨率等参数时补充测速，后续复用对应记录；不会自动改变所选编码格式或码率。不同编码器的同一画质值不保证相同画质。

背景视频分配

减少重复仅在本次队列的候选视频中生效，仍优先遵循风格。修改分配设置会重新分配未完成任务；已完成作品保留。没有背景的任务需调整后才能开始导出。

歌词处理

先使用歌曲自带或同名 LRC 歌词；在线匹配无结果或失败时，使用下方处理方式。

任务遇到错误时

关闭后，首次生成失败即停止新增任务，已经运行的任务会继续完成。按歌词设置跳过音乐不计为失败。同名输出会自动添加序号，保留已有文件。
