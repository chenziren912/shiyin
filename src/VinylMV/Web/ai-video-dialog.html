为每一首音乐创作风景

AI 背景视频

生成一段短视频，导出时自动循环铺满歌曲。服务费用与可用模型以你填写的 API 服务为准。

使用方式

视频生成接口

根地址可包含版本路径，例如 /v1/。模型列表仅用于读取名称，视频能力由生成时的实际响应确认。密钥使用 Windows 当前用户加密保存，留空保留已有密钥。

生成参数

标准 Videos 使用 4 / 8 / 12 秒及四种标准尺寸。帧率、种子和生成声音需由通用 JSON 请求模板引用；实际支持范围以服务商为准。MV 成片使用所选歌曲作为音轨。

画面方向

为滚动歌词设计的提示词

内置提示词组合场景、可观察的动态、镜头、光线与配色，并结合当前黑胶、歌词、时间和进度条的位置预留低干扰区域。可在每首音乐的“AI 提示词”中查看和修改。

模板变量：{title} 歌名、{artist} 歌手、{genres} 风格、{mood} 情绪、{scene} 场景、{style} 视觉风格、{camera} 镜头、{motion} 动感、{palette} 配色、{duration} 秒数、{aspect} 比例、{layout} 布局、{lyrics} 歌词。歌词需开启上方选项才会提供。

接口接收提示词与歌曲文字信息。开启歌词参考后会加入限定长度的歌词；生成流程使用文字，不上传原始音频。

文字模型润色

文字模型进一步整理画面意境与镜头细节；视频接口收到最终提示词。已有单首自定义提示词会直接使用。

生成队列

AI 并发还受批量任务总并发数限制。查询与下载可重试；创建视频任务不会因网络异常自动重发。停止本地队列后保留已提交的任务编号，下次优先继续查询；服务端任务可能仍在运行。

文件与复用

已生成视频保存在本机；重复导出可复用，已有文件不会被覆盖。更改模型、提示词、镜头或视频参数会匹配新的背景。

请求与结果映射

不同服务商的协议可能不同。通用 JSON 支持同步返回视频 URL，或创建任务后查询结果。字段路径支持 data.id、data[0].url、/data/id；多个候选可用 | 分隔。

请求模板变量：{model}、{prompt}、{seconds}、{size}、{width}、{height}、{aspect}、{fps}、{seed}、{generateAudio}、{negativePrompt}。值恰为变量时保留数字 / 布尔类型。附加头可引用 {apiKey}。API 密钥只发送给配置的同源接口，不转发给外部视频下载站点。
